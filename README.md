# Vue 2.5.2 + Vite

This project now targets `Vue 2.5.2` and `Node 20.14.0`.

Use `nvm use` after opening the repo, then install dependencies with `npm install`.
The project builds and runs using the checked-in `src/kibanaConsoleData.generated.js` file and no longer depends on any local `kibana-7.6.0` source directory.
